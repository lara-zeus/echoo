# Zeus Echoo

Zeus Echoo is filamentphp form component to record audio from your browser

## Features

- 🔥 Built with [TALL stack](https://tallstack.dev/)
- 🔥 Audio recording directly from the browser
- 🔥 Seamless upload using Filament's native features
- 🔥 Simple clean UI
- 🔥 Record and upload
- 🔥 Costumire the disc and directory
